# ADR-0001: 可自訂的表格模板系統

故事紀要工具需要支援不同的作品世界觀（咒術迴戰、一般超能力、奇幻等），每個世界觀需要不同的表格欄位。若硬編碼表格結構，每換一個題材就要改程式碼。

**決定：採用模板系統，一個模板定義一整套表格組合，但允許單獨替換某個表格的定義。模板庫存於 LocalStorage，故事 JSON 匯出時嵌入當前 schema。**

## 權衡

- **考慮方案 A：硬編碼表格** — 最簡單，但每換題材就要改 HTML，不利於通用化
- **考慮方案 B：僅使用者自訂欄位** — 靈活但從零開始太累，沒有起點
- **選擇的方案：內建模板 + 自訂修改** — 咒術迴戰模板開箱即用，通用模板可當起點，使用者可複製調整

## 儲存策略
- 模板庫獨立（LocalStorage），跨故事共享
- 故事匯出時嵌入 schema，確保接收方能完整還原
